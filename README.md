# Elliott Bowring portfolio

Static HTML, CSS and JavaScript portfolio positioning Elliott Bowring first as a Data Engineer, distinguished by architecture ownership, performance optimisation, applied machine learning and strong software-engineering practice.

## Preview

From this directory, run:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765`.

## Structure

- `index.html` contains the semantic portfolio content and page structure.
- `styles.css` contains the responsive editorial design system.
- `script.js` handles the mobile menu, sticky-header state and subtle reveal effects.
- `Assets/` contains approved public assets.

Project media, approved public contact links and downloadable documents will be added after review.
